# CRITERIA — Mobile Wrapper Reference

> The mobile app is a Capacitor shell that wraps the web frontend. No native logic lives here — it's purely a WebView wrapper with a dev launcher.

---

## Overview

```
mobile/
├── capacitor.config.ts       # Capacitor config (source of truth)
├── launcher/
│   ├── index.html            # Dev launcher — loads the app in an iframe
│   └── build/.gitkeep        # Placeholder (unused — kept for reference)
├── ios/                      # Xcode project (generated by Capacitor)
├── android/                  # Android Studio project (generated)
└── package.json
```

The `launcher/index.html` is the `webDir` — it's what Capacitor loads first. In dev mode it provides a floating debug button to switch the target URL. In production, `DEV_MODE` is set to `false` and it redirects straight to the deployed frontend.

---

## Dev Workflow

### 1. Start the frontend

```bash
pnpm --filter frontend dev --host
# → Network: http://192.168.x.x:5173
```

### 2. Sync Capacitor (only needed after changing `capacitor.config.ts` or native plugins)

```bash
cd mobile
npx cap sync
```

### 3. Open in Xcode / Android Studio

```bash
npx cap open ios
npx cap open android
```

### 4. Set the dev URL in the simulator / device

1. Run the app from Xcode or Android Studio
2. Tap the **⚙ button** (bottom-right corner) — only visible when `DEV_MODE = true`
3. Paste the network URL (`http://192.168.x.x:5173`)
4. Tap **Connect**

The URL is saved in `localStorage` — subsequent launches go straight to it. To disconnect, open the panel again and tap **Disconnect**.

---

## Switching to Production

1. Deploy the frontend (Vercel or similar)
2. In `mobile/launcher/index.html`, update the two constants at the top of the `<script>` block:

```js
var DEV_MODE = false
var PROD_URL  = 'https://criteria.vercel.app'
```

3. Run `npx cap sync` and rebuild the native project

## iOS Notes

- **Minimum target**: iOS 14 (Capacitor 6 requirement)
- **Tested simulators**: iOS 17.x, iOS 18.x — do **not** use iOS 26 beta (Capacitor 6 incompatibility)
- **Safe areas**: handled via CSS `env(safe-area-inset-*)` — `contentInset: 'never'` in config
- **Zoom**: disabled via `user-scalable=no` + `touch-action: manipulation`

### First-time Xcode setup

```bash
cd mobile
npx cap sync
npx cap open ios
```

In Xcode: select a simulator (iOS 17 or 18) → Run (`⌘R`).

If you see "Application failed preflight checks":
- Product → Clean Build Folder (`⇧⌘K`)
- Make sure you're targeting iOS 17 or 18, not iOS 26 beta

## Android Notes

```bash
npx cap open android
```

Run from Android Studio → select an emulator → Run.

## Adding Native Plugins

```bash
cd mobile
npm install @capacitor/camera        # example
npx cap sync
```

Plugins used (none yet — to be added in later phases):
- `@capacitor/camera` — property photo uploads
- `@capacitor/geolocation` — location input
- `@capacitor/push-notifications` — chat alerts

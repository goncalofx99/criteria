The [GDPR Article 13](https://eur-lex.europa.eu/eli/reg/2016/679) lists required collection-time information, including controller identity, purposes and legal basis, recipients, retention, rights, and applicable international transfers. ## Analytics decision

[Cloudflare Web Analytics](https://developers.cloudflare.com/web-analytics/about/) is the selected option for browser traffic and page-speed measurement: Cloudflare describes it as free and privacy-first. Its [setup](https://developers.cloudflare.com/web-analytics/get-started/) requires a Cloudflare site and token. It can [record SPA navigation](https://developers.cloudflare.com/web-analytics/get-started/web-analytics-spa/) and does not log query strings, but it [does not support custom events](https://developers.cloudflare.com/web-analytics/faq/), so it cannot directly measure a sign-up button conversion. This integration deliberately sets Cloudflare's documented `spa:false` option and skips single-use auth/account confirmation routes. It measures initial page loads and Core Web Vitals, with limited in-app route counts; this reduces exposure of OAuth and account-link flows to a third-party script.

The frontend now has a manual, opt-in beacon loader. `VITE_CLOUDFLARE_WEB_ANALYTICS_TOKEN` is a **public site token, not a secret**. Without it, no analytics script is requested and the banner only acknowledges necessary storage. With it, the real browser site offers equally visible `Essential only` and `Allow analytics` choices. The beacon is requested only after recorded opt-in on `criteria-app.com`; it is excluded from native, local development, preview hosts, review mode, and token-bearing auth/account routes. A choice is saved in browser local storage and can be reopened from Settings. Withdrawal reloads the page to stop any listeners from the downloaded beacon. If browser storage is blocked, the beacon stays off. Confirm the exact site token, hostname, CSP allowances, and network behaviour in staging before enabling it.

Cloudflare's [automatic setup](https://developers.cloudflare.com/web-analytics/get-started/) can inject a script outside this app when the domain is proxied. Set it to manual JS snippet installation or disabled; do not use automatic injection alongside this consent flow. The site token must be placed in the frontend deployment environment only after this is checked. The Privacy Policy and notice describe optional analytics; any future provider or measurement changes require a new review and, where appropriate, a renewed choice.
